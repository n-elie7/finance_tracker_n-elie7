FinanceAha a Student Finance Tracker

About This Project

FinanceAha is a personal finance tracker built for students who want a simple way to record expenses, set a monthly budget, and understand their spending habits.

It is built with pure HTML, CSS, and JavaScript, no frameworks or external libraries used. All data is stored locally in your browser using localStorage.

The app is fully accessible: it supports keyboard-only navigation, screen readers via ARIA live regions.
